# Основы веб-разработки для карьеры

Одностраничный сайт (лендинг) для онлайн-курса «Основы веб-разработки для карьеры». Разработан в рамках учебного проекта.

## Стек технологий

- **React 18** + **TypeScript**
- **Vite** — сборщик проекта
- **Tailwind CSS** — стилизация
- **shadcn/ui** — библиотека UI-компонентов

## Структура проекта

```
src/
├── main.tsx                  # Точка входа
├── styles/
│   ├── index.css             # Базовые стили
│   ├── tailwind.css          # Подключение Tailwind
│   ├── theme.css             # CSS-переменные темы
│   └── fonts.css             # Подключение шрифтов
└── app/
    ├── App.tsx               # Корневой компонент
    └── components/
        ├── Header.tsx        # Фиксированная шапка с навигацией
        ├── Hero.tsx          # Первый экран с основным оффером
        ├── About.tsx         # О курсе и ключевые цифры
        ├── Program.tsx       # Программа курса (аккордеон)
        ├── Benefits.tsx      # Преимущества курса
        ├── Portfolio.tsx     # Примеры работ учеников
        ├── Reviews.tsx       # Отзывы выпускников
        ├── Pricing.tsx       # Тарифы и стоимость
        ├── ApplyForm.tsx     # Форма заявки
        ├── Footer.tsx        # Подвал
        └── ui/               # Компоненты shadcn/ui
```

## Запуск проекта

**Установка зависимостей:**

```bash
npm i
```

**Режим разработки:**

```bash
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

**Сборка для продакшена:**

```bash
npm run build
```

Собранные файлы появятся в папке `dist/`.

**Предпросмотр продакшен-сборки:**

```bash
npm run preview
```
